# EdgeFX Studio v3

邊光／拖尾特效製作工具，網頁版。

線上使用：開啟本 repo 的 GitHub Pages 網址即可，所有處理都在瀏覽器本機完成，圖片不會上傳。

使用指南：同一個網址後面加上 `guide.html`。

更新方式：

- 工具：在原始專案執行 `python src/build.py` 產生 `edge-fx-tool-v3.html`，複製成本資料夾的 `index.html`。
- 指南：在原始專案執行 `python src/guide/build_guide.py --web`，會直接產生本資料夾的 `guide.html`。

改完 commit、push 即可。
