EdgeFX v3 使用指南

一個 HTML 檔就是整套工具：丟一張去背 PNG 進去，即時生出邊光、火焰、雷電、拖尾特效，再匯出去背 PNG、序列幀＋Spine JSON、分層 PSD。v3 在 v2 的引擎上重做了介面，並且加上了動態節奏、沿框繞行、逐圖層時間軸、鋼筆路徑編輯與全域搜尋。這份指南用白話把每個功能講一遍。

工具本體：開啟 EdgeFX Studio v3 →
快速上手 介面導覽 光貼著什麼走 圖層與風格庫 動態：節奏與繞行 圖層時間軸 速度總表與無縫 匯出 拖尾 TrailFX 路徑與鋼筆 盤面檢視與對位 快捷鍵 常見問題 v2 → v3

01 · Quick Start五步驟出一張圖

最常用的流程——給一顆 symbol 或一個中獎框加光效。

  1. 丟圖進去：把去背 PNG 直接拖進畫布，或按左欄「開啟去背 PNG…」。沒有素材可以按「範例圖」。要做純框光的話連圖都不用（見光貼著什麼走）。
  2. 套一個風格：左欄「3 風格庫」先點分類資料夾（繞框、火焰、雷電、聖光、水冰、魔法、爆裂），再點一張縮圖，整組圖層配方就套上去了。
  3. 挑一個動態：左欄「4 動態」按一顆節奏（心跳、燈管明滅…）或繞行（彗星繞行、描邊生長…），整組圖層一起動起來。
  4. 微調：右欄點任一圖層改顏色、寬度、強度；形狀不喜歡就按右下「隨機形態」的骰子重骰。
  5. 匯出：右上角「匯出」或 CtrlE，選單張 PNG、序列幀 ZIP、分層 PSD、批次或 Spine 骨架。
標題列的 v3 旁邊會寫建置時間。覺得新功能沒出現，先看那個時間對不對，再按 CtrlShiftR 重新載入——瀏覽器很愛拿舊的那份快取。

頂列分頁（邊光／拖尾）、復原重做、簡易／進階、搜尋、快捷鍵、重播導覽、匯出

簡易 ⇄ 進階

頂列的切換鈕（或 Tab）。簡易模式只留最常用的東西——動態區塊只剩模板按鈕、沒有滑桿，背景底圖與盤面檢視這些進階區塊整個收起來。剛上手或只想套現成配方就用簡易，要細調再切進階。

找不到某個功能？用搜尋

CtrlK 或頂列的放大鏡。打幾個字就會列出所有相關的設定——參數、開關、按鈕、下拉選單裡的選項、圖層參數、連風格庫的配方都找得到。按 Enter 它會自動幫你切分頁、切進階模式、展開收起來的區塊，捲到那個控制項上閃兩下。

記不得正式名稱沒關係，打你記得的那個詞就好——下拉選單裡的每一個選項也都有進索引，例如直接打「繞完一圈」會跳到拖尾的「模式」。

03 · Mask Source光貼著什麼走

特效不是亂長的，它會沿著一個「輪廓」生長。輪廓有兩種來源：

來源意思什麼時候用
前景圖的透明邊緣光貼著你丟進來那張圖的去背邊緣走symbol、角色、物件——形狀不規則的東西
矩形／圓角矩形／圓形框光沿著幾何框走，不需要圖片；畫布會自動貼合框的尺寸中獎框、按鈕框、轉軸格子框

框的寬、高、直徑、圓角旁邊都有數字框，要對齊遊戲截圖上的格子尺寸，直接把像素值打進去。

v3 的輪廓會逐塊分開追。v2 只追「由上往下掃到的第一個」邊界，所以像「YOU WIN」這種彼此分離的字，只有其中一塊會長出雷電。v3 會把圖裡每一塊各自追一圈，六個字母各自包一圈光，而且沿輪廓連續的效果（波光、貼圖邊光）是逐圈畫的，不會在兩個字之間牽出一條帶子。太小的雜點會自動濾掉。

特效被畫布邊緣裁到

火焰、光暈會燒出畫布外。畫布上方跳出紅色警告時，按自動外擴一鍵解決（右欄「全域與尺寸」也有外擴量的數字框可以手動給）。

匯出序列幀時工具會再掃一次每一幀的最外圈像素，確定沒被切到才報「N 幀最外圈都是全透明」；被切到會告訴你有幾幀、哪一側、最嚴重是第幾幀。這是最後一道防線，不必自己用眼睛檢查。

04 · Layers圖層與風格庫：效果是疊出來的

每個風格配方其實是「好幾層特效疊在一起」。例如烈焰邊光＝柔光墊底＋主火焰＋內緣亮邊。所以你可以：

  1. 點任一層，右欄下半就是它的參數——顏色、寬度、速度、強度、混合模式。
  2. 加減層：右欄上方選類型再按 ＋；不要的層按 🗑，或選起來按 Delete。V 可以暫時藏起來比較。
  3. 每層有「填滿內側」：關＝光只貼邊緣（邊光），開＝整個內部填滿（發光底板）。
  4. 存成自己的配方：左欄風格庫下面「儲存目前配方」，或「匯出 JSON」給同事。

邊光的八種圖層

類型長什麼樣類型長什麼樣
發散光柔邊外光暈，墊底或內緣亮邊火焰沿邊燒的火舌
光芒放射狀星芒，會旋轉雷電電弧、閃爍放電
星塵沿輪廓分布的粒子爆裂核心閃光＋衝擊環＋碎片＋火花＋煙霧
波光流動的波紋光帶貼圖邊光把一張貼圖沿著輪廓繞一圈跑

風格庫是分類資料夾

邊光七類、拖尾六類，每張縮圖都是用你當下的圖即時算出來的，所以縮圖長什麼樣，套下去就是什麼樣。Shift＋1…9 可以直接套目前資料夾的第 N 個。

種子（時間軸列最右邊）決定所有隨機形狀——雷電的長相、星塵的位置。同種子＋同參數＝結果完全一樣，方便重現；按骰子換一組新形狀。

05 · Motion動態：節奏與繞行

v3 最大的一塊。「這組光怎麼動」被抽出來放在左欄「4 動態」，一次套給整組圖層，不用每一層各調一次。

節奏（亮暗與變色）整組光一起呼吸、心跳、明滅、流動變色。14 組模板。
繞行與生長（只亮框的一段）讓光只出現在框的某一段，那一段會繞著框跑，或從 0 長到滿。11 組模板。

節奏模板

模板感覺模板感覺
緩慢呼吸最基本的一亮一暗警示閃爍一圈閃四次的方波
微微起伏幾乎看不出來的活著感連擊脈衝急亮緩滅，一圈三下
深呼吸慢慢蓄力再放開燭光搖曳不規則的小幅晃動
心跳 / 急促心跳雙峰的咚—咚波浪推進 / 輪流接力一層一層依序亮過去
蓄力緩亮急滅色相流動顏色繞整個色環一圈
燈管明滅方波式的開關兩色交替亮的時候偏到另一個色相

節奏的單位是「一圈呼吸幾次」，不是秒。所以不管循環長度設多少，尾幀接回首幀永遠對得上。次數刻意只能是整數——半次會讓首尾相位相反，接起來就跳一下。

繞行與生長模板

模板感覺模板感覺
彗星繞行（頭亮尾長）頭部過曝發白、往後拖一條長漸層尾巴光弧掃描 / 慢弧巡行一段柔邊的光弧繞框巡
雙彗星對向兩條彗星各佔半圈、對向跑描邊生長線從起點長到滿（進場動畫）
短彗星（快閃）短而亮，一圈跑兩趟雙向生長從同一點往兩邊長
光點繞行 / 雙光點對向一顆小亮點沿著框跑只亮一半 / 缺一角靜態地只顯示框的一部分
「描邊生長」本質是進場動畫，一圈結束會從滿跳回 0——拿它做無縫 loop 會看到那一下跳。要無縫就用繞行類（它們的圈數是整數，天生接得回去）。
貼圖邊光（band）不吃繞行遮罩，它有自己的「流速」參數。選到這種層時面板會用黃字提醒。發散光、光芒、火焰、波光、雷電、星塵、爆裂都支援。

這一層要不要跟著整組

圖層檢查器最下面有「這一層的動態」：跟隨開關＋慢幾拍亮（相位）＋繞行起點。底線、常亮的墊底層就把跟隨關掉；要做「一層一層推出去」的層次感，就把每層的相位錯開。

06 · Layer Timeline逐圖層時間軸：每層各演各的

時間軸列「時間」那格的第二顆鈕，兩個分頁都有。每一層一條軌，可以有自己的出現時機、長度、淡入淡出。

操作結果
拖區塊移動這一層的出現時機
拖左右邊改長度（區塊兩端的漸層＝淡入淡出）
×N邊光＝這一層的動畫快慢；拖尾＝在自己的窗裡跑幾圈
雙擊這條還原成整段
  • 預設值就是「整段、一倍速」，所以舊存檔與沒設定的層行為完全不變。
  • 視窗可以跨過結尾繞回開頭（軌道上會畫成兩塊），尾接首一樣無縫。
  • 淡入淡出是乘在整體的淡出上，不是取代——兩邊都設就會疊起來。
  • 細部數值（淡入淡出用拖的不準）在圖層檢查器最下面有滑桿。

拖尾分頁的時間軸列另外有一顆「播一遍就停」：跑到最後一幀停住不回頭，方便看進場動畫的收尾。只影響預覽，不影響匯出。

07 · Speed & Seam速度總表：一次看完所有會動的東西

以前速度散在各層的參數裡，單位還都不一樣（光芒是弧度、貼圖是格數、雷電是閃爍率）。速度總表把它們排成一張清單，全部換算成「每圈 N 次」——無縫 loop 真正在乎的就只有這件事。時間軸列「時間」那格的第一顆鈕，或點無縫指示就會開。

  • 標 ⚠ 的是小數次——尾幀接首幀會跳一下。按那一列的「對齊」四捨五入到整數次。
  • 整體速度 ÷2／×2：有週期的參數會順便 round 回整數次，所以加速完仍然無縫。
  • 標「沒有週期」的是噪聲流動（波光、火焰的速度），怎麼調都不影響無縫。
  • 標「每次重骰」的是雷電與星塵，形態每次重抽，匯出時靠尾幀的交叉淡化處理。
  • 改動會寫進資料，吃 CtrlZ。
時間軸列的「循環長度」那格多了一顆常駐的無縫指示：每半秒掃一次，顯示「✓ 無縫」或「⚠ N 項會跳」。以前要匯出之後用眼睛看才知道尾幀接不上。

09 · Trail FX拖尾分頁：畫一條路徑，光沿著飛

上方切到「拖尾 TrailFX」。用途：金幣飛行軌跡、集珠入袋、轉場流光、繞框跑的光帶。

  1. 畫路徑：左欄「2 路徑」按一個內建形狀（直線、S 曲線、弧線、圓形、8 字、螺旋、圓角矩形），或切到手繪工具在畫布上拖。
  2. 套風格：左欄「4 風格庫」，六類十四組。
  3. 選動態模式：見下表。
  4. 匯出：單張 PNG 或序列幀 ZIP＋Spine JSON。

模式行為適合

「繞完一圈」要勾起封閉路徑，頭才接得回起點。沒封閉時面板會跳黃字提醒，效果會跟「一次掃過」差不多。

畫布外擴

拖尾的畫布是自己設的（預設 1024×576），光暈很容易被邊緣裁掉。左欄「1 畫布」整組都在處理這件事：

  • 外擴量＋自動外擴：一鍵放大到剛好不會被裁。
  • 貼合光暈（縮到剛好）：反過來，把畫布縮到剛好包住光。
  • 縮放錨點：改尺寸時路徑要跟著置中，還是固定在左上。
  • 對齊倍數：輸出尺寸對齊到 4／8／16／2 的次方。
  • 被裁到就自動外擴：打開之後不用自己盯。
  • 畫布外的光暈用淡色畫出來：被裁掉的部分會在畫布外用半透明畫出來，一眼看出溢出多少（只是預覽，不影響匯出）。

下面的「留白」讀數會列出四邊各剩幾 px，負值＝被裁掉幾 px。

多路徑

每條路徑是完全獨立的一組：自己的特效層、顏色、動態模式、seed。點清單上的名字切換要編輯哪條；出發延遲讓某條晚一點出發，做「一條先飛、第二條跟上」的錯落感。清單前面的勾選框控制要不要進匯出——想每條各出一包 ZIP，就一條一條輪流獨顯著匯。

左欄「位置、尺寸與對齊…」摺疊裡還有：數值輸入位置與尺寸、鎖比例、置中、填滿畫布（會自動扣掉外擴量與光暈，縮到剛好不會被裁）、水平／垂直對齊、等距分布、平滑化、設為起點。

設為起點＝選一顆錨點，讓它變成路徑的第一顆（畫面上的綠點）。封閉路徑可以任選一顆，形狀完全不變、只是換了出發位置；開放路徑選最後一顆＝反轉方向。
v2 的「空白處拖曳＝整條重畫」這個破壞性行為，在 v3 被收進手繪工具裡了，平常不會再誤觸。要整條重畫請先按 D。

11 · Board View盤面檢視與背景對位

調好一顆之後，想知道「一次中 10 格、10 個框同時亮」會不會太吵？或是想確認框的尺寸對不對得上遊戲盤面？

拿背景底圖對位

左欄「1 素材 → 背景底圖」載入一張盤面截圖。直接在畫布上拖曳就是移動特效框（底圖不動），把框拖到要對的那一格上；Alt＋拖曳才是移動底圖。底圖只給預覽，不會匯出。

盤面檢視（分身）

  1. 勾「啟用」，畫布會切換成整張底圖。
  2. 雙擊要發光的格子 → 生出一個分身（＝你特效的複製品）。
  3. 拖曳對位；Shift＋滾輪 縮放單一分身（一般滾輪是縮放整個畫面）；右側清單也有 X／Y／縮放% 數字框。
  4. 中幾格就擺幾個，看整體觀感。看完按舞台上的「關閉」回到單顆編輯。

動態錯開勾著的時候，各分身的火焰／閃電會各燒各的、不會整排同步跳動，比較接近實機的感覺。

v3 在盤面檢視時也能拉控制點改尺寸（掛在最後點過的那個分身上，改的是共用尺寸，所有分身一起變）。舞台上會常駐顯示「盤面檢視中・N 個分身」＋關閉鈕，不會再搞不清楚自己在哪個模式。
盤面模式下特效只畫在分身身上——分身清單是空的就什麼都看不到。分身是純檢視功能，所有匯出都不含分身和底圖，永遠只出你調的那一顆本體。

13 · FAQ常見問題

我改好的東西好像沒生效／新功能找不到？
先看標題列 v3 旁邊的建置時間是不是最新的，再按 CtrlShiftR 重新載入。已經開著的分頁不會自動更新。
畫面上什麼都沒有／特效框叫不出來？
九成是「盤面檢視」開著但沒有分身——雙擊畫布新增一個，或按舞台上的「關閉」回到一般模式。
看不到控制點？
按舞台工具列的「控制點」鈕（或 T）。它關著的話按下去會說明目前為什麼顯示或隱藏。
火焰上下被切平了？
特效燒出畫布範圍了。按紅色警告上的「自動外擴」，或自己把外擴量調大。
匯出的動畫尾巴接回開頭會跳一下？
開速度總表看有沒有標 ⚠ 的小數次，按「對齊」或「全部對齊到整數次」。時間軸列的無縫指示平常就會告訴你有幾項會跳。
繞行模板套下去，貼圖邊光那層沒反應？
貼圖邊光不吃繞行遮罩，請改用它自己的「流速」參數。面板上選到那層時會有黃字說明。
想讓某一層一直亮著、不要跟著整組呼吸？
選那一層，圖層檢查器最下面「這一層的動態」把跟隨關掉。
匯出的圖比原圖小？
長邊超過 1600px 的來源圖會被自動縮到 1600 以內。要原尺寸請先把來源圖控制在 1600 內。
重開工具後背景底圖不見了？
底圖太大時瀏覽器存不下（localStorage 容量限制），會自動放棄存圖、保留其他設定。重新載入一次底圖即可。
序列幀要多少幀？
一般 loop 特效 30 幀 / 30 FPS（1 秒）夠用；動態慢的可以 60 幀。幀數越多 ZIP 越大、引擎記憶體越吃。
我的 v2 存檔和配方會壞嗎？
不會。v3 跟 v2 的設定分開存、互不干擾，v2 的 preset JSON 拿到 v3 開會自動補上新欄位的預設值，行為跟原本一樣。

14 · What's Newv2 → v3 有什麼不同

引擎（算圖的那一半）跟 v2 是同一套，所以畫出來的光完全一樣。變的是介面與「怎麼讓它動」。

面向v3 做了什麼
介面三欄式、冷色設計系統、步驟編號、簡易／進階模式、新手導覽、完整的復原重做
搜尋CtrlK 全域搜尋，連下拉選項與風格庫配方都找得到
動態節奏（呼吸光）14 組＋繞行與生長 11 組，整組一次套用；逐層可關跟隨、錯相位
時間軸兩個分頁都有逐圖層多軌時間軸；拖尾多「繞完一圈」模式與「播一遍就停」
速度速度總表統一換算成「每圈 N 次」、一鍵對齊、常駐無縫指示
路徑真貝茲控制桿、鋼筆／選取／手繪三工具、多選與對齊分布、設為起點
畫布拖尾新增整套外擴機制（自動外擴、貼合光暈、錨點、對齊、畫布外光暈預覽）
輪廓多連通輪廓：分離的字母／物件各自包一圈光
圖層新類型「爆裂」；風格庫改成分類資料夾（邊光 7 類、拖尾 6 類）
其他幾何框不需圖片、特效縮放、整體自由變形、畫布上的變形控制點、匯出前掃最外圈像素、自我診斷提示
